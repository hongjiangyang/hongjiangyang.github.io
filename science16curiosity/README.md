尚未经独立样本信效度验证；不得用于职业筛选或心理诊断。

原版保存在 Git 标签 `curiosity-v4-before-scenarios-2026-09-14`。可通过 GitHub 标签浏览旧版；回退时仅恢复 science16curiosity 目录，不回退网站其他模块。
